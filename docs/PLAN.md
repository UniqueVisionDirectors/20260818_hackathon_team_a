# 3D積み木ゲーム 仕様書

## 1. 概要

Babylon.jsを使用した3D積み木ゲーム。

ランダムに生成される3Dオブジェクトを床の上に積み上げ、**何個まで積めるかを競う**。

---

## 2. ゲームルール

1. ゲーム開始時に床を表示する。
2. 3Dオブジェクトを1つランダム生成する。
3. プレイヤーがオブジェクトの位置・向きを調整する。
4. DROPすると重力によって落下する。
5. オブジェクトが安定したら次のオブジェクトを生成する。
6. 床から落ちたオブジェクトを失敗としてカウントする。
7. 一定回数失敗するとゲーム終了。
8. 最終的に積み上げた個数をスコアとする。

---

## 3. 使用技術

* TypeScript
* Babylon.js
* Babylon.js Physics V2
* Havok Physics

Havok Physicsを使用して以下を実現する。

* 重力
* 衝突判定
* 摩擦
* 反発

---

## 4. 物理設定

### 重力

```ts
new Vector3(0, -9.81, 0)
```

を基本値とする。

### 反発係数

積み上げた際に跳ねにくくするため、低く設定する。

```text
restitution = 0 ～ 0.05
```

### 摩擦係数

オブジェクトが滑りにくくなるよう、高めに設定する。

```text
friction = 0.7 ～ 0.9
```

---

## 5. 3Dオブジェクト

最初はBabylon.jsの基本形状を使用する。

* Cube
* Sphere
* Cylinder
* Box

ゲーム開始時はCube中心とし、スコアが増えるにつれて積みにくい形状を増やしてもよい。

---

## 6. オブジェクト操作

DROPする前だけ操作可能とする。

### 移動

```text
X方向
Z方向
```

に移動できる。

### 回転

オブジェクトを回転できるようにする。

### DROP

```text
Spaceキー
```

などでオブジェクトを落下させる。

DROP後はそのオブジェクトを操作できない。

---

## 7. ターンの流れ

```text
オブジェクト生成
      ↓
位置・回転を調整
      ↓
DROP
      ↓
重力で落下
      ↓
衝突
      ↓
安定判定
      ↓
次のオブジェクト生成
```

---

## 8. 安定判定

DROP直後に次のオブジェクトを出さず、現在のオブジェクトがほぼ停止してから次のターンへ進む。

例えば、

```text
移動速度 < 0.1
回転速度 < 0.1
```

の状態が一定時間続いたら安定と判定する。

---

## 9. 落下判定

床より十分下まで落ちた場合、失敗とする。

例：

```ts
if (object.position.y < -5) {
    // 落下
}
```

---

## 10. スコア

正常に積み上げることができた場合、

```text
Score + 1
```

とする。

画面上に、

```text
SCORE: 12
MISS: 1 / 3
```

のように表示する。

---

## 11. ゲームオーバー

初期仕様では、

```text
3回落下
```

したらゲームオーバーとする。

```ts
const MAX_MISS_COUNT = 3;
```

ゲームオーバー画面では、

```text
GAME OVER

SCORE: 24
```

を表示する。

---

## 12. カメラ

Babylon.jsの`ArcRotateCamera`を使用する。

プレイヤーが積み木を様々な角度から確認できるようにする。

* オブジェクトを回転できる

## 15. 実装順

```text
① Babylon.js Scene作成

② Camera / Light / Floor作成

③ Havok Physics導入

④ Cubeを落下させる

⑤ Cube同士を積めるようにする

⑥ 移動・回転・DROP操作

⑦ ランダムオブジェクト生成

⑧ 落下判定

⑨ Score / Game Over

⑩ UIや演出を追加
```

まずは、

**「Cubeを自由な位置から落として、Cubeの上にCubeが積み上がる」**

ところまでを最初の目標とする。
